Jarir Blog — Demo Credentials
==============================

These accounts are seeded by `php artisan db:seed` and exist for local
development only. Do NOT use these credentials in any deployed environment.

Demo Admin
----------
  Email:     demo@jarir.test
  Password:  password
  Name:      Demo Admin
  Role:      admin (full access to /admin SPA + admin API)

How to log in
-------------
  1. Run the dev servers:

         php artisan serve
         npm run dev

  2. Open http://localhost:8000/login in your browser.
  3. Enter the email and password above.
  4. After signing in, visit http://localhost:8000/admin to manage posts
     and moderate comments.

Verifying the credentials via tinker
------------------------------------
    php artisan tinker
    > \App\Models\User::where('email', 'demo@jarir.test')->first()->toArray();

Re-seeding
----------
  php artisan migrate:fresh --seed      # nukes the database and re-seeds
  php artisan db:seed                   # adds rows without dropping

Notes
-----
  - The password is intentionally simple ("password") because this is a
    local-only demo. Change it before deploying anywhere.
  - The Breeze registration form at /register will let you create
    additional accounts, but they will not be flagged as admins.
  - This file is meant to live in the repo so collaborators have a known
    login. If you fork this for production, delete it or replace it
    with a stub.
